# Topics leaned

We learned a lot in this chapter 👏👏👏

<v-clicks>

- Recognise Python's core data types: strings (`str`), whole numbers (`int`), and decimal numbers (`float`)
- Convert between types using `int()`, `float()`, and `str()`
- Perform arithmetic using Python's operators: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- Understand and apply order of operations (PEMDAS) when writing expressions
- Fix type errors that occur when mixing strings and numbers
- Format decimal output using f-string specifiers like `:.2f`
- Use `round()`, `min()`, and `max()` for common number tasks

</v-clicks>
