# Shorthand Assignment operators

When modifying a variable based on its current value:

```python
score = 5
score = score + 1   # Long way
score += 1          # Shorthand (same result)

# All shorthand operators:
x += 5    # x = x + 5
x -= 5    # x = x - 5
x *= 5    # x = x * 5
x /= 5    # x = x / 5
```
