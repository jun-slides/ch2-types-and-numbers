# Useful Number Functions

### Rounding Numbers

Use `round()` to round numbers:

```python
print(round(8 / 3))      # 3 (rounds to nearest whole number)
print(round(8 / 3, 2))   # 2.67 (rounds to 2 decimal places)
```

### Ceil and Floor

```python
import math

print(math.ceil(5.1))      # 6  (always rounds up)
print(math.floor(5.9))     # 5  (always rounds down)

```
